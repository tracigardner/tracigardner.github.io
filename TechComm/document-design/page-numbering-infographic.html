Page Numbers

Follow the Report Roadmap

A formal report has three numbering zones. Follow the changes in numbering, and include optional sections only when needed.

Optional sections: Include only when they help your readers. Omit unnecessary sections and keep page numbering continuous.

Route 1 · Separate document

Letter of Transmittal

Use Arabic numerals. Leave the first page unnumbered. If the letter continues, number subsequent pages 2, 3, and so on. The letter is separate from the report.

1
First page
(no number)
2
If needed
Route 2 · New numbering sequence

Front Matter

Use lowercase Roman numerals. Count the title page as i, but do not print its number. Show ii on the next page.

i
Title page
(no number)
ii
Next page
iii
Following page
Front Matter Sections
  • Title Page
  • Table of Contents
  • List of Illustrations Optional
  • Abstract
  • Executive Summary
Route 3 · Restart at 1

Report Body + Back Matter

Use Arabic numerals. Start the Introduction at 1, show that number, and continue consecutively through the final appendix.

Report Body Sections
  • Introduction
  • Methods
  • Results
  • Conclusions

Back Matter Sections
  • Glossary Optional
  • List of Symbols Optional
  • References
  • Appendices Optional

Keep numbering. Continue Arabic page numbers through the back matter without restarting at 1.

Keep Your Place

Count the title page without displaying its number. Keep Arabic numbering continuous from the Introduction through the back matter, without restarting for individual sections.
